# Portfolio Website

A modern, responsive portfolio website built with HTML and Bootstrap 5.

## 📁 Files

- **index.html** - Main portfolio website
- **styles.css** - Custom styling and animations
- **README.md** - This file

## 🎨 Features

- ✅ Responsive Design (Mobile, Tablet, Desktop)
- ✅ Modern UI with smooth animations
- ✅ Sticky Navigation Bar
- ✅ Multiple Sections:
  - Hero/Home Section
  - About Me
  - Skills
  - Projects Portfolio
  - Work Experience
  - Contact Information
  - Social Media Links
- ✅ Bootstrap 5 & Font Awesome Icons
- ✅ No Authentication Required
- ✅ Easy to Customize

## 🚀 Getting Started

1. **Open in Browser**: Simply open `index.html` in your web browser
2. **Customize Content**: Replace placeholder text with your actual information
3. **Add Images**: Replace image filenames with your own images:
   - `profile-image.jpg` - Your profile photo
   - `about-image.jpg` - About section image
   - `project1.jpg`, `project2.jpg`, `project3.jpg` - Project thumbnails

## 📝 Customization Guide

### 1. **Personal Information**
Update these sections in `index.html`:
- Name in navbar: `<a class="navbar-brand">Himanshu</a>`
- Hero title and subtitle
- About section content
- Contact email: `your.email@example.com`
- Phone number: `+1 (234) 567-890`

### 2. **Skills Section**
Modify the skill cards with your actual skills:
```html
<h5>Your Skill Name</h5>
<p class="text-muted small">Technology1, Technology2, Technology3</p>
```

### 3. **Projects Section**
Update each project card with:
- Project title
- Project description
- Technologies used (badges)
- Project image
- Project link

### 4. **Experience Section**
Add your work experience with:
- Date range
- Job title
- Company name
- Key responsibilities/achievements

### 5. **Social Media Links**
Replace `#` with your social profile URLs:
- LinkedIn
- GitHub
- Twitter
- Instagram

### 6. **Images**
Place your images in the same folder:
- Profile photo (150x150px recommended)
- About section image (400x500px recommended)
- Project thumbnails (500x300px recommended)
